# Lacoste Designs — rebuild landing

Standalone static page for Netlify Drop or a second Netlify site.
Does not replace the main Vite app in `/app`.

## Deploy
1. Zip or open the `rebuild-landing` folder.
2. Go to https://app.netlify.com/drop and drag the folder in.
3. Site settings → Forms — confirm `rebuild` is listed.
4. Optional: assign a domain such as rebuild.lacostedesigns.com.

Form submissions go to Netlify Forms. Inbox: lacostedesigns@protonmail.com.
